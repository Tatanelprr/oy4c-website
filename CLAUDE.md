## Règles Git

- Travailler uniquement sur la branche `dev`.
- Commencer chaque tâche par `git branch --show-current`.
- Si la branche courante est `main` : s'arrêter et prévenir Ethan, sans changer de branche.
- Ne jamais faire `git switch main` / `git checkout main`, ni merge, ni cherry-pick vers `main`.
- Ne jamais pousser (`git push`).
- Messages de commit sans trailer (pas de `Co-Authored-By`) ni mention de Claude.
